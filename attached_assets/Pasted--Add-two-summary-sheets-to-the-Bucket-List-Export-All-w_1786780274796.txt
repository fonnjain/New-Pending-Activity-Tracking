## SHEET 1 — "Summary"

Two blocks on one sheet. **Pre-B is excluded from this sheet.**

### Block 1 — Bucket overview, one row per bucket

Columns: `Bucket` · `Meaning` (merged across two columns) · `Rows` · `Projects` ·
`Structures` · `Release Bal. (MT)` · `Fab (MT)` · `Galva (MT)` · `Yard (MT)` · `Total (MT)`

One row each for A, B, C, D, E. `Rows` is the count of project-batch rows on that bucket's
sheet, `Projects` the distinct project count.

For bucket A leave the four weight columns **blank** and put its Order Qty in `Total (MT)` —
A has no pending weight, and its measure is the order quantity, not shop-floor weight.

### Block 2 — By project and MFC batch

One row per distinct `(project, MFC batch)` across buckets A–E, sorted numerically by project
then by batch, with non-numeric project codes (VS-, VR-, RAILWAY) sorted after the numeric ones.

Columns: `Project` · `MFC Batch` · then **two columns per bucket** — `MT` and `Str.` — under a
merged, colour-coded group header naming the bucket.

`MT` is Order Qty for A and `Rel. Bal. + Fab + Galva + Yard` for B, C, D and E. Leave both cells
**empty** where that project-batch does not appear in that bucket — do not write zeros, since an
absent row and a zero row mean different things. Shade the filled cells in the bucket's colour so
membership reads at a glance.

Expected: **173 rows**, and a bold TOTAL row matching the Block 1 totals per bucket.

Freeze panes below the column headers and to the right of `MFC Batch`.

## FORMATTING FOR BOTH SHEETS

Use one shared palette, keyed by bucket, for the title bands and cell shading:

```
A  fill D9E2F3  text 2F5597        D  fill DDEBF7  text 2E75B6
B  fill FCE4D6  text C55A11        E  fill E4DFEC  text 7030A0
C  fill E2EFDA  text 548235
```

Headings in `1F3864`, muted notes in `595959`, thin borders in `BFBFBF`, medium borders in
`1F3864` on block edges. Weight columns `#,##0.000`, counts `#,##0`. Gridlines off. Title in row
1, and a grey subtitle in row 2 giving the source file name and the as-at date.

Column widths: project and batch around 11, structures around 9.5, date columns 15, weight
columns 12.5.
