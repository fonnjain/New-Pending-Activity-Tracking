CONTEXT (read before coding)
=====================================================================
This is the VTPL Balance & Activity Tracker. The deterministic engine is
authoritative; nothing here may change parsing, Activity values, qty, dedup/hash
identity, or ageing math. This feature is STRICTLY ADDITIVE and READ-ONLY over
existing data (it only READS order_review_rows + record_pool + contractor_categories;

The page has FIVE buckets. EVERY bucket is split into two sides: IN-HOUSE and
OUT-VENDOR (two columns / two sub-lists per bucket).

  A — "Project to Start"                         (MANUAL entry)
  B — "Raw Material Incomplete"                   (AUTO from Order Review)
  C — "RM Complete – Material Under Production"    (AUTO from Order Review)
  D — "Dispatch Clearance Recd But Production Not Complete" (AUTO from Order Review)
  E — "Material Ready But Not Dispatched"          (MANUAL entry)

Buckets B, C, D MAY OVERLAP — a structure can appear in more than one of them
simultaneously. Do NOT apply any precedence/de-dup across B/C/D.

Data source for B/C/D is the LATEST Order Review import (order_review_rows for the
newest order_review_imports.id), one row per (project, structure). Column meaning

  - structure          = Order Review Col C (Tower Type code = WIP Alias; the JOIN key)
  - fileBalReleaseMt   = Order Review Col S  (Balance → Release MT)
  - Progress→Inspection (MT) = Order Review Col O.
       IMPORTANT: verify the field name for Col O "Progress → Inspection (MT)" in

       and fileBalReleaseMt/fileBalDespatchMt (Balance block). If a Progress-Inspection

       `inspectionMt double precision` (Progress block, Col O), additively, and
       backfill on next Order Review upload. Do NOT confuse it with the BALANCE

  B  → fileBalReleaseMt >  0
  C  → fileBalReleaseMt <= 0        (numeric; null balance release = EXCLUDE, flag it)
  D  → inspectionMt (Col O Progress) > 0

Rows where the relevant column is null/blank are EXCLUDED from that bucket and counted
in a small "excluded (no data)" footer per bucket — never silently dropped.

Project codes: normalize with the EXISTING normalizer (strip trailing dot / .0) before
