=====================================================================
THE RULE
=====================================================================
The Cutting (C) balance must count ONLY marks where:
        Col G "Job Card Status" == "Authorized"
and must EXCLUDE marks where Col G == "Initial".

Job Card Status on Cutting marks has EXACTLY TWO values in the source data — "Authorized" and
"Initial". There is no third case, no blank, no variant spelling. So the filter is a clean
binary and there is no data-quality excuse for a partial result.

Every Cutting mark also has Col A "Type" == "Job Card Not Started", so filtering on
Status == "Authorized" is sufficient and equivalent to excluding Type+Status = Not Started +
Initial.
