REPLIT AGENT PROMPT — "PLANT OPERATION WISE" PAGE (Fabrication + Galvanization tabs)
====================================================================================
Add a new nav page "Plant Operation Wise" with two tabs: "Fabrication" and "Galvanization".
It respects the TLT / NTLT toggle. For now only the TLT side is built; NTLT shows "Coming
soon". Primary grouping inside each tab is by PROJECT, then CONTRACTOR. Display/aggregation
page; do not change parsing, ageing, dedup, classification, or the alert math — reuse what
exists.

    category/group_key classification, hole_operation (PUNCHING/DRILLING/NOT_SET),
    thickness_mm, contractor fields — all already in the records. Reuse them.

PAGE & TABS
  - Add "Plant Operation Wise" to the nav.
  - Two tabs at the top: [ Fabrication ] [ Galvanization ].
  - The page respects the global ORDER TYPE toggle (TLT / NTLT) and the global filters
    (contractor, date, etc.).

------------------------------------------------------------
TAB 1 — FABRICATION
------------------------------------------------------------
TLT mode:

    HG, W, Q) i.e. TLT_FABRICATION.
