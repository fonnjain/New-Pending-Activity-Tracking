## PART 1 — signature A is defined wrongly

I wrote the test as *"every cumulative column **falls to** zero"*. That is wrong. It should be
*"every cumulative column **ends at** zero"*.

The difference is why three of four blocks came back as "treat with caution":

```
775       all six columns non-zero before, all zero after   -> matched A
896       Progress Despatch was ALREADY 0.000, so it did
          not FALL to zero                                  -> failed A, fell to C
VS-189    Inspection and Despatch both already 0.000        -> failed A, fell to C
```

896 and VS-189 are cancellations. They behave exactly like 775 — whole order zeroed, structure
list replaced. The only difference is that they had not despatched anything yet, so some columns
were already at zero and had nowhere to fall from.

### Corrected definition

```
Signature A · likely cancellation or scope transfer

    project present in both files
AND every cumulative column ENDS at zero (within tolerance)
AND WO Order Qty ENDS at zero
AND at least one column actually decreased
```

The last clause keeps a project that was already entirely zero on both days from being classified
as a cancellation.

Under this, 775, 896 and VS-189 all classify as A — which is what they are.

## PART 2 — there is a fourth signature I never defined

840 came back as "unrecognised" because no rule covered it. It is not a cancellation and not a
correction. **The order itself shrank.**

```
840   WO Order Qty       370.608 -> 357.143   -13.465
      Progress Release   374.700 -> 361.237   -13.463
      Fabrication        374.700 -> 361.237   -13.463
      Galvanising        374.700 -> 361.237   -13.463
      Inspection         364.005 -> 350.615   -13.390
      Despatch           271.432 -> 261.205   -10.227
```

Every stage followed the order down by almost exactly the same amount. At structure level, 1DA2
went 3.124 → 0.281, 1DB2 7.071 → 2.004, 1DC2 3.673 → 1.130 — quantities reduced, not removed. And
two structures moved **upward**: 1DD2A +0.406 and 1DD9M +2.624.

That is a scope reduction — towers taken out of the order, with a little reallocation.

### New definition

```
Signature D · likely scope reduction

    project present in both files
AND WO Order Qty decreased
AND WO Order Qty in the incoming file is greater than zero
AND at least one cumulative column decreased
```

Message: **"Looks like the order itself was reduced."** State that WO Order Qty came down and the
stages followed it, and list any structures that moved upward — reallocation within a reduced
scope is a strong corroborating signal.

### Check the four are mutually exclusive

A requires WO Order Qty to end at zero; D requires it to end above zero. B requires WO Order Qty
unchanged. C is everything else. Confirm no observed case matches two, and that C is now genuinely
rare rather than the default.
