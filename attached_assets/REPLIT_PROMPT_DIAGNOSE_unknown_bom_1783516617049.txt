BACKGROUND
=====================================================================
In this report, BOM Label (Proto / Mass / Pre) comes from the Order Review sheet and is
attached to each WIP mark by joining the mark's (project, structure) to Order Review.
"Unknown" is the fallback when a mark's structure cannot be resolved to a BOM Label.

A LEGITIMATE Unknown example is project 946: it appears in WIP with active fabrication but
is NOT present in the current Order Review file at all, so no BOM Label can be assigned —
that is correct behaviour.

Unknown group), but 920 SHOULD have ZERO Unknown. Verified against the raw files:
  - 920 has 67 distinct WIP structures (Alias values).

  - Every one of those Order Review structures HAS a BOM Label (Proto/Mass/Pre).
  - Therefore every 920 WIP mark should resolve to a BOM Label; Unknown for 920 should be 0.

W≈16.452, Y≈9.514, G≈7.304, NH≈5.044, GB≈1.096. The Unknown bucket is catching a small
slice of this that should have been labelled.
