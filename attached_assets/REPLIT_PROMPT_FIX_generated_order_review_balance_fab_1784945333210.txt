TASK: The generated Order Review (Data page) computes Balance Fabrication wrongly — it counts
UNRELEASED marks as pending fabrication, inflating the figure massively. Fix it so the released
/ not-released split is applied BEFORE the stage mapping.

=====================================================================
THE SYMPTOM
=====================================================================
For newly-started projects the generated Balance Fabrication is far too large — it equals the
whole work order instead of just the released portion:

    Project   Generated Balance Fab   Actual Order Review   should be
    948            279.925                   6.028            6.028   (46x too high)
    960            146.101                   2.043            2.043
    937             74.481                   3.190            3.190
    958             18.374                   8.891            8.891

The Release columns are ALREADY correct (Progress Release and Balance Release reconstruct
exactly). Only the Fabrication / Galvanising / Yard stage split is wrong.

=====================================================================
THE ROOT CAUSE
=====================================================================
The generator currently maps a mark to a stage bucket by its ACTIVITY alone (C, RFI, ... ->
fabrication). But a mark sitting at activity C in the "Job Card Not Started + Initial" state is
NOT in fabrication — it has not been released yet. It is unreleased raw material and belongs to
Balance RELEASE, not Balance FABRICATION.

Order Review is a WATERFALL: a mark cannot have "balance to fabricate" until it has been
released. So the released/not-released split must be applied FIRST, and only RELEASED marks are
then distributed across the fabrication/galvanising/yard stages.

=====================================================================
THE CORRECT GENERATION LOGIC (per project + structure, TLT only)
=====================================================================
For each mark, first classify RELEASED vs NOT RELEASED:
        NOT RELEASED = Type (Col A) == "Job Card Not Started" AND Status (Col G) == "Initial"
        RELEASED     = every other mark

Then:
    Balance Release (S)   = sum Balance Wt of NOT-RELEASED marks
    Progress Release (L)  = sum Balance Wt of RELEASED marks
                            (everything that has been released, whatever stage it is now at)

    *** All remaining stage buckets use RELEASED marks ONLY. ***
    Balance Fabrication (T)  = sum Balance Wt of RELEASED marks still in fabrication activities
                               {C, HG, RFI, NH, B, HAB, W, Q, TS}
    Balance Galvanising (U)  = sum Balance Wt of RELEASED marks not yet galvanised
    Progress Fabrication (M) = released marks that have passed fabrication (galvanising / FG)
    Progress Galvanising (N) = released marks at yard / FG (galvanised)
    Balance Inspection (V)   = released marks not yet inspected (all except FG Pending)

A NOT-RELEASED mark contributes ONLY to Balance Release. It must never appear in any
fabrication, galvanising, yard or inspection bucket.
