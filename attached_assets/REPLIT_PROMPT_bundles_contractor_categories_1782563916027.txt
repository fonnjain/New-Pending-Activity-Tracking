REPLIT AGENT PROMPT — ACTIVITY BUNDLES + CONTRACTOR SUB-CATEGORIES (TLT-namespaced)
===================================================================================
Add (1) activity "bundles" as filter shortcuts in the activity dropdown, and (2) three
contractor sub-categories marked in the database, including the out-vendor list with
FAB/GALVA tags. TLT-specific bundles are NAMESPACED with "TLT" so NTLT equivalents can be
added later without collision. Deterministic/display + DB tagging; do not change parsing,
ageing, dedup, or the alert math.

==========================================================
PART 1 — ACTIVITY BUNDLES (filter shortcuts in the activity dropdown)
==========================================================
A "bundle" selects a SET of activities at once (filter shortcut). Individual activities stay
selectable. Define bundles with explicit IDs and scope:

  TLT-scoped bundles (shown only when ORDER TYPE = TLT):
    id "TLT_FABRICATION"        label "Fabrication (TLT)"
        activities = [C, RFI, NH, B, HAB, HG, W, Q]            (C -> Q)
    id "TLT_FAB_PENDING_QUALITY" label "Fab - Pending Quality (TLT)"
        activities = [RFI, NH, B, HAB, HG, W, Q]               (RFI -> Q)

  All-order-type bundles (shown for TLT and NTLT):
    id "GALVANIZING"  label "Galvanizing"   activities = [TS, G, GB]
    id "YARD"         label "Yard"          activities = [Y]

  NAMESPACING: the TLT-only bundles carry "TLT" in BOTH id and label so that when NTLT
  bundles are added later (e.g. "NTLT_RSJ_FABRICATION" for NTF/NTFSW/NTFW) there is no
  collision. Galvanizing/Yard are shared (no category prefix) since they apply to all types.

  DROPDOWN BEHAVIOUR:
    - In TLT mode: dropdown shows the bundles (Fabrication (TLT), Fab - Pending Quality
      (TLT), Galvanizing, Yard) as a "Bundles" group at the top, then individual activities
      in TLT sequence order below.
    - In NTLT mode: show ONLY Galvanizing and Yard bundles (NOT the TLT fabrication bundles),
      then NTLT individual activities (NTF, NTFSW, NTFW, TS, G, GB, Y) in NTLT sequence
      order. (No NTLT fabrication bundle for now.)
    - Selecting a bundle filters to marks whose CURRENT activity is in the bundle's set.
    - Define bundles in ONE constants module keyed by id, each with {label, activities[],
      scope: "TLT" | "ALL"}, imported wherever the activity filter is built. Reuse the
      per-category sequence ordering already in place.

  Apply the bundle filter consistently across pages that have the activity filter (Overview,
  Activity, Ageing, Job-wise/Section-wise, Reports/exports).
