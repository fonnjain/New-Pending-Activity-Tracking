## PART 1 — DC17's categories do not match what was built

The report labels categories by **gap magnitude**:

```
A = any positive gap        B = -0.05 to -5 MT
C = -5 to -20 MT            G = balanced
```

The version implemented in `dataCheck.ts` labels them by **failure mode**, keyed on WIP pending
weight (W), Progress Despatch (Q) and WO Order Qty (J):

```
positive gap (J - Q - W > +0.05):
  A  W = 0 and Q = 0     never started - no job card, nothing shipped
  B  W = 0 and Q > 0     left WIP with no despatch record
  C  W > 0 and Q = 0     in production, WIP short of the work order
  D  W > 0 and Q > 0     partly shipped, WIP short of the remainder

negative gap (J - Q - W < -0.05):
  E  J = 0               marks in WIP with no work order
  F  |J - Q| <= 0.05     fully despatched per the order book, marks still pending
  G  everything else      shop holds more than the order book expects
```

Structure `884/2MD2` at −7.727 MT was **category F** when DC17 was first spot-checked. It is
labelled **C** in this report. Same structure, same number, different letter.

**Answer before changing anything:**

1. Which classification is live in the app right now — the failure-mode one or the magnitude one?
2. Did `artifacts/api-server/src/scripts/verify-disk.ts` reimplement the classification, or does
   it import it from the same place `dataCheck.ts` uses?

If it reimplemented it, that is a second definition of the same rule sitting in the codebase —
the same problem we fixed by moving `QC_ACTIVITY_SET` and `GALV_ACTIVITY_SET` into `lib/domain`.
Export the classifier from one module and have both call sites import it. Do not leave two.

**Why the failure-mode version is the one that matters:** the magnitude bands put all 440
positive structures into a single group worth +2,155 MT. That group mixes category A — a work
order raised and nobody has cut it yet, which is benign and roughly 70% of the total — with
category B, material that has left the shop floor with no despatch record. B was 37 structures
and 261.573 MT, and it is the only part of DC17 anyone needs to act on. A magnitude band cannot
separate them; only the W and Q tests can.
